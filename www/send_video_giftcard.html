🎬 MLQ Video Giftcard — send_video_giftcard v0.1

หน้าแยกสำหรับ “ประกอบวิดีโอ” โดยใช้ Video Template จาก Google Drive + Music File + ข้อความ แล้วส่งไปยัง Cloud Run เพื่อ Render Output กลับมาเป็นวิดีโอจริง

⚙️ v0.1 = Single Video Template Only ☁️ Cloud Run Render 🎵 Google Drive Music File ID 🪪 ยังไม่ผูก DNA Engine เต็มระบบ

1) Render Mode + Cloud Run

เลือกประเภทงานที่จะส่งไป render และระบุ base URL ของ Cloud Run service

v0.1 รองรับ 2 mode ก่อน: showcase และ gift
ไม่ต้องใส่ path เช่น /render/showcase — ระบบจะต่อ endpoint ให้เองตาม render type
ตอนนี้ให้ใช้ single เท่านั้น ตัวอื่นเก็บเป็นโครงสำหรับ v0.2
ช่องนี้ยังไม่ถูกส่งให้ backend โดยตรงใน v0.1 แต่เก็บไว้ใน preview เพื่อช่วยจัดระเบียบงาน
Endpoint mapping v0.1
- ถ้า Render Type = showcase → POST ไป /render/showcase
- ถ้า Render Type = gift → POST ไป /render/gift

2) Video Template จาก Google Drive

ระบุไฟล์วิดีโอ template ที่จะใช้เป็นภาพหลักในการ render

หมวดนี้เป็น metadata ฝั่งหน้าเว็บ เพื่อช่วยคุมการเลือก template ให้ตรง usage
ใช้เก็บชื่อที่คนอ่านรู้เรื่อง ไม่จำเป็นต้องตรงกับชื่อไฟล์จริง
ใส่ File ID ของวิดีโอ template จาก Google Drive — นี่คือค่าหลักที่ Cloud Run จะใช้ดาวน์โหลดไฟล์จริง
ใส่ไว้เพื่ออ้างอิง/เปิดดูเองจากหน้าเว็บ ไม่จำเป็นต่อ backend ถ้ามี file id อยู่แล้ว
v0.1 ยังเป็น single video template เท่านั้น — ยังไม่รับหลายคลิป / intro / outro ใน payload จริง

3) Music / DNA Audio Source

v0.1 ใช้แนวทางง่ายก่อน: ใส่ Music File ID จาก Google Drive โดยตรง

v0.2 ค่อยต่อกับระบบ DNA music ที่สร้างไฟล์เพลงอัตโนมัติจากหน้าเดิม
ใส่ File ID ของไฟล์เพลง MP3 / WAV ที่ต้องการใช้แทนเสียงเดิมของวิดีโอ

4) Render Settings

กำหนดช่วงเวลาที่จะใช้จากคลิปต้นฉบับ และข้อความ overlay ที่ต้องการส่งไป render

เช่น 60 = เริ่มที่นาที 1 ของ template
เช่น 30, 45, 60
ยังเป็น metadata ฝั่งหน้าเว็บเพื่อช่วยจัด flow / naming
ใช้กับ showcase เป็นหลัก แต่ใน gift ก็ยังส่งไปได้หาก backend รองรับ
สำหรับ showcase v0.1 ใช้ title_text เป็นข้อความหลัก และไม่บังคับ recipient/message

5) Meta / Job Notes (ไม่บังคับ)

เก็บบริบทของงานไว้กับ payload preview เพื่อช่วยจัดระเบียบการทดสอบและตามผล

ข้อมูลชุดนี้จะไม่ทำให้ Cloud Run render เก่งขึ้นใน v0.1 แต่ช่วยให้ payload preview อ่านรู้เรื่องและย้อนดูงานทดสอบได้ง่ายขึ้น
