📸✨ โปรดิวซ์เซอร์ภาพถ่าย + อินโฟกราฟิก ✨🐾

สร้าง Prompt สำหรับ AI รูปภาพ | ภาพสัตว์จริง/เด็กจริง + ข้อความหลัก + คำพูดตัวละคร + สัดส่วนภาพตามแพลตฟอร์ม

✅ ภาพถ่ายจริงเท่านั้น • เลือกขนาดภาพให้พอดีกับโซเชียลมีเดีย
🧸✨ หลักการสร้าง Prompt ✨🧸
📌 ไม่ใช้ข้อความขัดแย้ง • คล้อยตามแล้วใช้มุกหักมุม • หาเนื้อหาเพลง • เน้นน่ารัก อมยิ้ม 🍭

📌 1. หมวดอารมณ์

✨ รายละเอียดเพิ่มเติม

🐾 Option 1 · ตัวละคร (ถ่ายจริง)

✏️ หรือพิมพ์เอง
ตัวละคร: แมว (ภาพถ่ายจริงเท่านั้น)

🧸 Option 2 · ท่าทาง / Pose

🍀 สัตว์มงคล + แพะยิ้ม
🖌️ หรือพิมพ์ท่าทางเอง
ท่าทางที่ใช้: lying comfortably...

📢 Option 3 · ข้อความหลัก (Main Headline)

📝 ข้อความ headline 金色ตัวใหญ่ด้านล่าง
🎨 สไตล์ตัวอักษรหลัก

💬 Option 4 · คำพูดตัวละคร (Speech Bubble)

🗣️ ข้อความที่ตัวละครพูด (ใส่ใน bubble)
🎲 ตัวอย่างคำพูดฮาๆ

📐 Option 5 · สัดส่วนภาพ / แพลตฟอร์ม

เลือกขนาดภาพที่ต้องการ (เปลี่ยน --ar ใน prompt)
ป้อนสัดส่วนเอง (เช่น 3:2, 7:5)
⚡ สัดส่วนภาพจะถูกเพิ่มท้าย prompt เช่น --ar 9:16

✏️ แก้ไข Prompt ได้โดยตรง

✨ Option 5 ช่วยปรับสัดส่วนภาพให้ตรงกับแต่ละแพลตฟอร์ม ลดการครอปภายหลัง

🧠 แนวทางน่ารักอมยิ้ม + มุกหักมุม

🍭 ไม่ใช้ข้อความขัดแย้ง: เลี่ยงคำรุนแรง ใช้มุขแบบ “แพะไม่ได้โม้” หรือ “ขี้เกียจแต่รวย”
🎭 คล้อยตามแล้วหักมุม: เริ่มเหมือนซีเรียส แต่จบฮา เช่น “ฉันคือแพะรับบาป... แต่วันนี้ขอยิ้ม”
🎶 หาเนื้อหาเพลง: อาจแทรกคำร้อง เช่น “ยิ้มเข้าไว้... แล้วชีวิตจะดี๊ดี”
😊 เน้นน่ารัก อมยิ้ม: ใช้คำว่า ยิ้ม, อมยิ้ม, น่ารัก, พองฟู
📸 ภาพถ่ายจริงสัตว์/เด็ก + ข้อความและสติกเกอร์ได้เต็มที่
